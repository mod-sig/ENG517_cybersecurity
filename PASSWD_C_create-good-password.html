  1. How to Create and Protect a Good Password

How to Create and Protect a Good Password

When an account requires a password, use a long, unique password and protect it with additional security measures such as multifactor authentication and a password manager.

Understand why passwords can be compromised

Passwords can be exposed in several ways. A phishing message may direct you to a fake sign-in page that collects your credentials. Attackers may also obtain password data from a website breach and try commonly used or previously exposed passwords.

Using the same password for multiple accounts increases the risk. If one service is breached, attackers may try the exposed password on your other accounts.

Choose a long, unique password

If a website or service requires you to create a password, NIST recommends using at least 15 characters. Length is especially important because longer passwords generally require more guesses to discover.

A passphrase made from multiple words can help you create a password that is long and easier to remember. Create a different password or passphrase for each account. Never reuse a password across your NC State and personal accounts.

NIST no longer recommends requiring every password to contain a particular mix of uppercase letters, lowercase letters, numbers, and special characters. A website may still impose its own character requirements, so follow the requirements shown by the service you are using.

Important: Do not use a password or passphrase shown in an article, example, or training material. Public examples are no longer secret and should never be used to protect an account.

Use a password manager

A password manager can generate long, unique passwords and store them securely, so you do not have to memorize or write down every password. Choose a password manager that supports multifactor authentication (MFA), and enable MFA for the password manager account when it is available.

Check current NC State guidance before assuming that a university-provided password manager is available for your role or account type.

Turn on multifactor authentication

Multifactor authentication (MFA) adds another verification step when you sign in. It can help protect an account even if someone obtains its password. Depending on the service, the second factor may be an authenticator app, a push notification, a security key, or a code.

When an account offers MFA, turn it on. Some methods provide stronger protection against phishing than others. Follow the security options recommended by the service or your organization.

NC State uses Duo for multifactor authentication on applicable university accounts. For an explanation of Duo Mobile, see What Is Duo Mobile at NC State?.

Consider using a passkey

A passkey is an alternative to a password. It uses a digital credential stored on a device, such as a phone or computer, to verify your identity. You may unlock it using your device PIN or a biometric method, depending on the device.

Passkeys are specific to the service for which they are created and are designed to resist common phishing attacks. Use a passkey when a trusted service offers it and it meets your access needs.

Note: Passkey availability and sign-in options vary by service and device. This topic does not establish whether a passkey can be used for a particular NC State account.

Learn more

For additional recommendations, read the NIST guidance on creating a good password and securing online accounts.

For NC State-specific account requirements and assistance, consult the current university IT guidance or contact the NC State IT Service Portal.
