  1. Choose the Right NC State Wi-Fi Network

Choose the Right NC State Wi-Fi Network

NC State students, faculty, staff, and visitors can select from three wireless networks. The appropriate network depends on the user's university affiliation and the device being connected.

About NC State's wireless networks

NC State provides three wireless networks for people who need internet access on campus. Each network is intended for a different group of users or type of device.

eduroam

The recommended, secured, and encrypted network for NC State students, faculty, and staff. Eligible visitors from participating eduroam institutions may also connect using credentials from their home institution.

ncsu (Nomad)

An unsecured and unencrypted network for devices that cannot connect to eduroam, such as some gaming consoles, smart TVs, and other multimedia devices. It is not the preferred network for ordinary university computing.

ncsu-guest

A guest network for visitors, recruiters, alumni, and other guests who need campus internet access and are not connecting through eduroam. Users must accept the network's terms and conditions.

Select a network based on your role

Students

Connect personal and university-supported devices to eduroam. Enroll each device using the NC State eduroam setup process.

Faculty

Use eduroam on supported laptops, phones, tablets, and other compatible devices. Follow the enrollment procedure with your NC State Unity credentials.

Staff

Use eduroam on supported devices for a secured wireless connection. Follow university IT guidance for any university-managed equipment.

Visitors

If your home institution participates in eduroam, connect using your home institution's eduroam credentials. Otherwise, select ncsu-guest and accept its terms and conditions. Visitors should not use an NC State Unity ID unless one has been issued to them.

Choose a network for a device that cannot use eduroam

If a device does not support eduroam, such as some smart TVs or gaming consoles, check the NC State wireless guidance for the appropriate connection method. The ncsu (Nomad) network is intended for these types of devices and is not encrypted.

Security and enrollment

Use eduroam when you are eligible and your device supports it because it provides an encrypted wireless connection. The ncsu (Nomad) network is unencrypted. Guest users should use the guest network or eduroam through their participating home institution.

NC State's wireless guidance states that eduroam enrollment must be renewed every five years. If a device stops connecting or its enrollment expires, follow the current enrollment instructions to enroll again.
