Connect to NC State Wi-Fi

Follow the instructions for your role and device to connect to eduroam, ncsu-guest, or the ncsu (Nomad) network on campus.

These instructions are for NC State students, faculty, staff, and visitors who need wireless internet access on campus. Complete the procedure that applies to your role and device; you do not need to complete every audience-specific procedure.

Students, faculty, and staff: Use eduroam on supported devices. The Windows 10 and 11 enrollment procedure below uses SecureW2 JoinNow and your NC State Unity credentials.

Visitors: If your home institution participates in eduroam, use its eduroam credentials. Otherwise, connect to ncsu-guest and accept the terms and conditions. You do not need an NC State Unity ID to use the guest network.

Devices that cannot use eduroam: Consult the NC State wireless website for guidance about ncsu (Nomad), which is intended for certain devices such as gaming consoles and smart TVs.

For an overview of the networks and help choosing one, see Choose the Right NC State Wi-Fi Network.

  1. Identify the Wi-Fi network that applies to you.

    • NC State students, faculty, and staff: choose eduroam.

    • Visitors whose home institution participates in eduroam: choose eduroam and use your home institution credentials.

    • Other visitors: choose ncsu-guest.

    • Devices that cannot use eduroam: consult the NC State wireless website for ncsu (Nomad) guidance.

  2. If you are an NC State student, faculty member, or staff member using Windows 10 or 11, enroll your device in eduroam by following these substeps. If this does not describe you, skip to the procedure that applies to your role.
    1. Open the SecureW2 eduroam enrollment page.

      Check that the page identifies your device's operating system as Windows.

    2. Select Join Now to download the SecureW2 JoinNow program.

      Wait for the download to finish before opening the installer.

    3. Locate and run the downloaded SecureW2 wrapper program.

      Find the downloaded file named WiFi_North_Carolina_State_University_Wrapper and open it.

      If Windows displays a permission prompt, review it and select Yes to continue if you initiated the installation.

      If the program does not open correctly, right-click the wrapper file and select Run as administrator, if permitted on your device.

    4. Continue with the SecureW2 installation.

      When the SecureW2 installation window appears, select Next.

    5. Sign in with your NC State Unity credentials.

      In the browser window that opens, authenticate through Shibboleth using your Unity ID and password. Select LOG IN.

    6. Complete the eduroam configuration.

      Allow SecureW2 JoinNow to install the wireless configuration. When the process finishes, select Done.

    7. Verify that Windows is connected to eduroam.

      When the device is within range, it should connect automatically. To check its status:

      1. Open Windows Settings.

      2. Select Network & Internet, then Wi-Fi.

      3. Confirm that eduroam displays the status Connected.

  3. If you are a visitor who is not using eduroam through a participating home institution, connect to ncsu-guest by following these substeps.
    1. Open the Wi-Fi settings on your device.

      On your phone, tablet, or computer, open the wireless network settings and view the available networks.

    2. Select ncsu-guest from the list of available networks.
    3. Complete the guest access prompt.

      When the guest access page appears, read and accept the terms and conditions to continue.

    4. Verify that your device has internet access.

      Open a web browser and visit a website to confirm that the connection is working.

  4. If you are a visitor from an institution that participates in eduroam, connect using your home institution's credentials.
    1. Open your device's Wi-Fi settings and select eduroam.
    2. Sign in using the eduroam credentials and configuration supplied by your home institution.

      Do not enter an NC State Unity ID unless NC State has issued one to you. If your device has not been configured for eduroam, contact your home institution's IT support for setup instructions.

    3. Verify that your device connects to eduroam and can access the internet.
  5. If your device cannot use eduroam, consult the NC State Wireless Network Access website for the appropriate ncsu (Nomad) connection guidance.

    The ncsu (Nomad) network is intended for certain devices that cannot use eduroam, such as some gaming consoles and smart TVs. It is unsecured and unencrypted.

Your device should connect to the appropriate NC State wireless network when it is in range and the required enrollment or guest access steps have been completed.

If eduroam enrollment or connection does not work, check that you entered the correct credentials and repeat the enrollment procedure if necessary. If the device is managed by NC State, follow your department's IT support process.

For additional assistance, visit the NC State IT Service Portal or contact the NC State Help Desk at 919-515-4357 (HELP).
